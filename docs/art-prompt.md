# アイコンの依頼文

`assets/icon-source.png` は ChatGPT に次の2通で作った。1通目で方向を決め、2通目で小さいサイズでの見え方を直した。
作り直すときはここから始める。

## 1通目

```text
macOS のアプリアイコンの原画を1枚、画像で生成してください。

アプリ名は Hawky。メニューバーに常駐して、AI のコーディングエージェントが許可待ちで止まっていると知らせ、押すとその画面へ飛んで連れて行くアプリです。「高いところから見張り、見つけたら一直線に降りてくる鷹」がモチーフです。

- 形式: 正方形 1024×1024。背景は四隅まで塗り切った正方形にしてください。角丸は付けないでください（こちらで付けます）
- 主役: 白い鷹を1羽だけ。翼をたたんで、左上から右下へ斜めに急降下している横向きの姿。鋭い目とくちばしが分かるように
- 画風: 白い影絵に、ごく淡い陰影だけを付けたフラットなベクター風。細い線や細かい羽の描き込みはしない。太い面で形を取る
- 背景: 左上の明るい琥珀色（#FFB23E 前後）から、右下の深い朱色（#E4412B 前後）への滑らかなグラデーション
- 余白: 鷹の全体が、外周15〜20%の余白の内側に収まるように。どこも端で切らない
- 文字、ロゴ、枠、影の落ちた床などは一切入れない
- 要素は鷹と背景だけ。星や光の粒も入れない

16px まで小さくしても鷹の形だと分かることが一番大事です。
```

返ってきた絵は、16px と 32px で「白い羽」にしか見えなかった。頭が小さく、全体が細長かったため。

## 2通目

```text
方向はとても良いです。ただ 16px と 32px に縮めると、鷹ではなく「白い羽」や「葉」に見えてしまいます。次の点だけ直して、もう1枚生成してください。背景のグラデーションと画風はこのままで。

- 頭を今の2倍くらいの大きさにして、画面の中心寄りに置く。鷹の頭とくちばしが、アイコン全体の主役になるように
- 体と翼は短く詰めて、全体をずんぐりした塊にする。細長く伸びた羽先は無くす。羽の枚数を減らし、翼は大きな面1〜2枚で表す
- 急降下の向き（左上から右下）は保つ
- 鷹の全体を外周20%以上の余白の内側に収める。特に左上の羽先が端に寄らないように
- 目は大きめに、はっきりと
```

これを採った。32px でも目と曲がったくちばしが残り、猛禽だと分かる。
